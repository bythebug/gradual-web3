# Gradual Web3

A practical, job-focused Web3 learning roadmap — one concept at a time.

**Live site → [bythebug.github.io/gradual-web3](https://bythebug.github.io/gradual-web3/)**

Built for people who want to become employable as a junior smart contract engineer, DeFi developer, or Web3 frontend developer. Not research-heavy. No whitepapers unless they're genuinely necessary. Just the tutorials, docs, and courses that actually teach you to build.

## Features

- Single HTML file — no build step, no dependencies, works offline
- Progress tracking via localStorage — picks up where you left off
- Filter by status (To Do / Done) and difficulty (Foundational / Intermediate / Advanced)
- Search across all resources
- Dark and light theme
- Fully responsive

---

## Who this is for

Someone with basic programming experience who wants to break into Web3. You don't need to know Solidity or blockchain before starting — the Foundational track assumes nothing. By the end of the Advanced track + Projects, you'll have the skills and portfolio to apply for real roles.

The Competitive Auditing section is especially worth doing — finding even one bug on Code4rena or Sherlock is the clearest signal a junior can show to hiring teams.
